# Agency Poem

Entry for make.fun competition `agency-poem-01`: "Write the best poem about agency".

`main.ts` (Node 22, standard library only) writes one short poem about agency — the power to choose and to act — to `/output/entry.txt` (1–1,000 Unicode code points, at least one non-whitespace character).

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
